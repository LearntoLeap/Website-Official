## Thay đổi

- Thêm thư mục `nhat-ky/`: mỗi thay đổi website kèm một file ghi người sửa, đơn vị, loại thay đổi, trang ảnh hưởng, chi tiết và lý do.
- Thêm `tools/nhat-ky.mjs` để kiểm tra file nhật ký và in bảng tổng hợp (`npm run nhat-ky`).
- Thêm mẫu Pull Request, `CODEOWNERS` (Learn to Leap duyệt mọi thay đổi) và hướng dẫn `CONTRIBUTING.md` cho nhà phân phối.
- Bảo vệ nhánh `main`: chỉ sửa qua Pull Request, cần Learn to Leap duyệt.

## Lý do
