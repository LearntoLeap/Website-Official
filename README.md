# Nhật ký thay đổi website

GitHub tự ghi mỗi lần có người đẩy thay đổi lên [LearntoLeap/Website-Official](https://github.com/LearntoLeap/Website-Official): **ai đẩy** (tài khoản GitHub đã đăng nhập), lúc nào, lên nhánh nào, từng commit kèm mô tả và từng file thay đổi.

"Người đẩy" là tài khoản GitHub thật đã đăng nhập khi đẩy. "Tác giả ghi trong commit" do máy người sửa tự khai, dùng để tham khảo.
